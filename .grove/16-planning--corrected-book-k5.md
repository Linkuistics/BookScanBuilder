## Notes

The two-stage boundary remains preparation by explicit inputs, then one PDF
through the processor. The user's shell owns collection iteration. An already
assembled PDF is valid input; the processor never discovers cover files.

Default cleanup is geometry and scanner-border removal with colour/detail
retained. A successor appearance increment in this tree supplies previewable
optional whitening/noise removal. Automatic work is followed by flagged-page
review, any page can be adjusted, and every accepted
change must appear in the final image and its OCR. The eventual design must
choose the least interface that supports this, based on trial evidence.

Grow the next actionable leaves only. Unknown correction technology, confidence
calibration and review-interface mechanics belong in the brief until a precise
question can be cut. Report unsupported cases honestly rather than silently
relaxing the root's quality requirements.
